easyprep STEM code checker

For teachers. Each virtual lab gives the student a completion code that is tied to the name they typed. Paste names and codes here to confirm the codes are real and to see what each student did.

Separate the name and the code with a comma or a tab, so you can paste two columns straight from a spreadsheet. The name must match what the student typed in the lab. Capital letters do not matter.

How the codes work

A code packs three things: which lab it came from, a few facts about the student's run (for example which orders were delivered, or the reading they recorded), and a check letter worked out from those facts and the student's name. If a student copies a classmate's code, or changes a digit, the check letter almost always stops matching and this page marks it Not valid. Codes from Mole Delivery, Bounce Energy Audit, Chemical ID, the Bungee Safety Challenge, the Collision Lab and the Recoil and Propulsion Lab end in two check letters, so about 1 copied code in 650 slips through. Labs that still use one check letter let about 1 in 26 through. The last column shows what the code says the student did, which you can compare with their lab sheet.

Nothing you type here is saved or sent anywhere. The checking happens on your own device.
